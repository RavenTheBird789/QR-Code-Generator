# QR Code Generator ⛶
Python script that converts the input provided by the user into a QR code using the python qrcode and pillow libraries and saves it as a local file

Requirements:
* Ensure the latest version of python is installed in your terminal (python 3.x)

Download:

```bash
git clone https://github.com/RavenTheBird789/QR-Code-Generator
cd QR-Code-Generator
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

Executing the software:

```bash
python3 QR_Code_Gen.py
```

Optional shortcut

```bash
alias qr="python3 QR_Code_Gen.py"
```
